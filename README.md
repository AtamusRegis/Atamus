A browser based game prototype sandbox

- The game: https://atamus.io (single player in the browser, GitHub Pages, from `website/`)
- Server: https://play.atamus.io (Node behind Caddy, from `packages/server/`; only the deploy hooks now)

Working on the code: [`CLAUDE.md`](CLAUDE.md), which covers the layout, the PTR test copy, the test suite and the deploy flow.
